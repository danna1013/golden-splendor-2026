# 2026 Golden Splendor - 新年粒子手势交互

## 项目描述

这是一个创意十足的新年互动网站，融合了粒子特效、手势识别和照片墙功能。用户可以通过手势与屏幕上的粒子进行实时交互。

## 功能特性

- 🎆 **粒子特效系统** - 精美的金色粒子动画效果
- 🤖 **手势识别** - 基于MediaPipe的实时手势识别
- 📸 **照片墙功能** - 上传并展示个人照片
- 🎂 **蛋糕聚合效果** - 握拳时粒子聚合成蛋糕形状
- 🎵 **背景音乐** - 沉浸式音乐体验
- 📱 **完全响应式** - 支持桌面、平板和手机设备

## 交互指南

- **握拳** - 聚合粒子成蛋糕
- **张开五指** - 散开照片墙
- **向右挥动** - 旋转视角
- **捏合手指** - 抓取查看照片

## 技术栈

- Three.js - 3D图形库
- MediaPipe - 手势识别
- Tween.js - 动画库
- WebGL - 高性能图形渲染

## 部署

本项目已部署在Vercel上，支持自动部署和持续集成。
